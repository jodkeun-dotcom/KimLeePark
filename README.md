# 기후위기 속 춘천 상권의 매출 회복 분석

### 극한기상 이후 고객 연령대별 카드매출은 얼마나 빨리 회복될까?

2026 빅콘테스트 AI 데이터분석 분야 **「기후 위기에 따른 취약 상권 영향 분석」** 참가 프로젝트입니다.

**팀명:** 김이박\
**팀원:** 김세은 · 박선하 · 이조은

## 1. 프로젝트 소개

폭염·집중호우 등 극한기상은 소비자의 외출과 소비 활동에 영향을 줄 수 있습니다. 같은 기상 상황에서도 업종과 고객 연령대에 따라 매출 감소 정도와 회복 속도가 다르게 나타날 수 있습니다.

이 프로젝트는 **춘천시의 카드매출·기상자료를 활용해 극한기상 이후 업종 및 고객 연령대별 매출 회복 양상을 분석**합니다. 이를 통해 기후위기에 취약한 상권의 특성을 파악하고, 소상공인을 위한 대응 및 지원방안을 제안하고자 합니다.

### 주요 분석 질문

- 극한기상 이후 어떤 업종과 고객 연령대에서 매출 감소가 크게 나타나는가?
- 매출이 평상시 수준으로 회복되는 데 얼마나 걸리는가?
- 회복이 느린 업종과 고객층을 위해 어떤 지원이 필요한가?

## 4. 설치 및 실행 방법

### 사전 요구사항

- Python 3.10 이상
- Git
- 공모전에서 제공받은 데이터 파일

제공 원본·레이아웃·정제 데이터는 저장소에 포함하지 않습니다. 전처리 전에 참가자가 제공받은 입력 파일을 로컬에 준비해야 합니다. 가상자료 결합 검사는 제공 데이터 없이 실행할 수 있습니다.

### 저장소 다운로드 및 패키지 설치

```bash
git clone https://github.com/jodkeun-dotcom/KimLeePark.git
cd KimLeePark
python -m pip install -r requirements.txt
```

### 데이터 준비

제공받은 파일을 로컬 환경의 다음 경로에 보관합니다. `data/README.md`와 `data/manifest.json`만 Git으로 관리하고, 나머지 `data/` 하위 파일은 `.gitignore`로 제외합니다.

```text
data/
├── README.md         # 입력 준비 안내 (Git 관리)
├── manifest.json     # 파일명·행수·해시 등 메타정보 (Git 관리)
├── skt/              # 로컬 SKT 원본 CSV 또는 CSV.GZ
├── shinhan/          # 로컬 신한카드 원본 TXT 또는 TXT.GZ
├── layouts/          # 로컬 제공기관 레이아웃 설명서
└── processed/        # 코드 실행으로 생성하는 로컬 정제 결과
```

SKT 원본 18개를 `data/skt/`에 준비합니다. 신한카드 데이터1은 아래 예시에서 `data/shinhan/shinhan_card_data1.txt`로 복사해 사용합니다. 원래 파일명을 유지한다면 명령의 `--input`을 실제 경로로 바꾸면 됩니다. 자세한 파일 구성과 중복 제거 기준은 [데이터 준비 안내](data/README.md)를 참고합니다.

### 전처리 실행

```bash
# SKT 유동인구 정리 및 월별 요약
python scripts/prepare_skt.py \
  --input data/skt \
  --output data/processed/skt

# 신한카드 데이터1 정리
python scripts/prepare_card.py \
  --input data/shinhan/shinhan_card_data1.txt \
  --output data/processed/card
```

위 명령은 로컬에 준비한 입력을 사용합니다. 두 전처리 코드는 압축된 CSV.GZ/TXT.GZ도 지원합니다. SKT 코드는 지정된 12월 파일의 완전 중복을 제거하며, 이미 중복 제거된 입력이면 추가 제거 행수는 0입니다. 출력은 `data/processed/`에 생성되며 Git에 포함하지 않습니다. [10월 1일 결과 목록](docs/status_1001.md)에서 검증 기록과 확인 대기 항목을 확인할 수 있습니다.

### 결합 코드 검사

python -m unittest discover -s tests -v

## 5. 주요 기능 및 사용법

### ① 유동인구 데이터 정리

- 지정된 12월 파일의 완전 중복 제거
- 결측값·음수·중복 키 점검
- 월별 연령·시간대·요일별 지표 집계
- 월별 관측 격자와 6개월 공통 격자 비교

### ② 카드매출 데이터 정리

- 춘천 개인카드 자료 추출 및 법인 제외
- 날짜·업종·연령별 매출 집계
- SKT와 비교할 수 있도록 60대 이상 연령대 통합
- 월별 매출·결제건수 집계

### ③ 데이터 결합

- 일별 카드매출과 기상·공휴일 자료 연결
- 중복 결합으로 매출이 부풀려지는 문제 검사
- 누락 날짜 및 결합 전후 행수·합계 확인
- 지역코드 확정 후 카드·SKT 월별 자료 비교

### ④ 매출 회복 분석 — 예정

- 극한기상 사건 정의
- 요일·공휴일 등의 차이를 고려한 평상시 매출 추정
- 업종 및 고객 연령대별 매출 감소·회복기간 비교
- 취약 업종에 대한 대응 및 지원방안 제안

### 결과 화면 — 추후 추가

현재는 데이터 정리와 분석 준비 단계입니다. 분석이 완료되면 다음 그래프와 설명을 추가할 예정입니다.

- 극한기상 전후 일별 매출 변화
- 업종·고객 연령대별 회복기간 비교
- 월별 카드매출과 유동인구 지표 비교

## 6. 분석 시 유의사항

- SKT 격자값 합계는 중복 없는 방문자 수를 의미하지 않습니다.
- 관측되지 않은 값은 임의로 0으로 처리하지 않습니다.
- 월별 흐름의 변화만으로 기후의 인과효과를 단정하지 않습니다.
- 데이터 결합 코드 작성과 실제 통합 데이터 검증 완료를 구분합니다.
- 외부 데이터는 출처·수집방법을 기록하고 원본을 별도로 보관합니다.
