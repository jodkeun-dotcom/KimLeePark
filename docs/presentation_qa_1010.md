## #18 관련 추가 질문

- 7일·14일은 언제부터 세는가: 회복 설명은 사건 종료일 기준이다. 운영 점검은 개별 검토 착수일 기준의 제안이며 실제 지원 시작일은 별도 기록한다. 두 기준을 같은 일정으로 합치지 않는다.
- 58%·89%는 전체 업종 회복 확률인가: 회복 확인 99개만의 첫날 분포다. 전체 감소 대상의 회복 확률·지원 효과·최적 지원 시점을 입증하지 않는다. 설명 통계의 추가와 사용 범위는 공동 확인 전이다.
- 왜 85×6×3과 1,473행이 다른가: 실제 관측된 업종·연령 조합은 491개다. 존재하지 않는 조합을 0으로 만들지 않았으므로 가능한 모든 조합의 곱과 다르다.
