# 세은 2차 추가 확인: 판정 범위·결측 원인·연령별 공휴일

검토 대상은 동일 공통 기준선의 ALL 255건과 연령별 1,473건입니다. 회복 기준 95%·3일 연속과 현재 기본 규칙을 유지했습니다. 아래 비중·건수는 검토용이며 원본 매출·개별 업종 수치는 공개하지 않습니다.

## 판정 가능한 업종의 예상 매출 비중

판정 가능은 회복 상태가 insufficient_data가 아닌 경우(감소 없음·회복·관찰기간 내 회복 미확인 포함)입니다. 분모는 해당 사건·기간의 모든 연령에서 계산된 예상값의 합이며 실제 관측 유무와 관계없이 포함했습니다. paired 합계만 분모로 쓰면 실제 결측이 있는 업종을 과소 반영하므로 사용하지 않았습니다. 예상값이 없는 셀은 임의로 보충하지 않습니다. 따라서 아래는 **존재하는 예상값 중 비중**이며, 알 수 없는 예상값까지 포함한 전체 매출 비중이 아닙니다.

| 사건 | 판정 가능/전체 | 사건기간 예상 비중 | 전체 창 예상 비중 | 사건기간 예상값 셀 존재율 | 전체 창 예상값 셀 존재율 |
|---|---:|---:|---:|---:|---:|
| ALL_EVENTS | 58/255 | 63.15% | 68.52% | 74.08% | 73.56% |
| HEAT03 | 15/85 | 61.50% | 61.91% | 71.46% | 68.64% |
| HEAT04 | 15/85 | 64.25% | 64.64% | 77.70% | 78.24% |
| HEAT05 | 28/85 | 75.76% | 81.44% | 79.23% | 78.66% |

3사건 합계는 겹치는 사건 창의 평가 단위를 합산한 비중이며, 중복을 제거한 전체 달력 매출 비중이 아닙니다. 판정 가능한 22.7%의 업종×사건이 알려진 예상값에서 상대적으로 큰 비중을 차지합니다. 자료 부족 건을 지원 필요가 낮다고 해석하지 않으며, 판정 가능 표본만으로 전체 업종을 대표할 수 있다고 주장하지 않습니다.

## 판정 불가 원인

현재 197건 중 사건기간 그룹 불완전 196건을 원인 유형으로 분해했습니다. 업종×사건 단위에서 예측 부재만 있으면 예측만, 실제 자료 부재만 있으면 실제만, 두 종류가 하나라도 있으면 두 종류로 분류합니다. 두 종류는 동일 셀에서 동시에 빠졌다는 뜻에 한정되지 않습니다. missing_row_unknown은 원자료의 관측값을 확인할 수 없다는 뜻이며 실제 매출 0이나 거래 없음으로 해석하지 않습니다.

| 사건 | 예측 부재만 | 실제 자료 부재만 | 두 종류 모두 | 사건기간 완전이나 이후 판정 불가 | 합계 |

## 결측 연령 하나 제외 진단

업종×사건마다 비공휴일 창에서 실제 또는 예상이 없는 셀 수가 가장 많은 연령 하나를 고릅니다. 동률이면 연령 라벨 사전순으로 고르고, 같은 연령을 모든 날짜에서 고정 제외한 경우만 셉니다. 마지막 연령까지 제거해 빈 집합을 완전으로 처리하지 않습니다. 선정에 평가기간 자료를 사용하므로 **진단 전용**이며 학습 기간에 미리 선정한 고정 구성 모델이 아닙니다. 연령 제외를 기본 계산에 적용하지 않고 금액도 재계산하지 않았습니다.

| 사건 | 원래 사건기간 불완전 | 하나 제외 후 새 사건기간 완전 | 새 비공휴일 전체 창 완전 | 새 달력 전체 창 완전 |
|---|---:|---:|---:|---:|
| ALL_EVENTS | 196 | 83 | 81 | 55 |
| HEAT03 | 70 | 25 | 26 | 0 |
| HEAT04 | 70 | 30 | 28 | 28 |
| HEAT05 | 56 | 28 | 27 | 27 |

완전해진다는 것은 해당 범위의 실제·예상 셀이 모두 존재한다는 뜻이며, 양의 예상 합이나 3일 연속 회복까지 보장하지 않습니다. 사건기간 완전성과 관찰기간 완전성을 분리해 논의할 근거로 사용합니다. 공휴일이 포함된 달력 전체 창과 비공휴일 창도 구분했습니다.

## 공동 안건과 전달본

공동 결정 안건은 (1) 전체 연령 완전 기준과 학습 기간에 미리 정한 고정 구성 중 선택, (2) 사건기간 전체 완전 요구와 관찰기간 연속 평가 조건의 분리, (3) 평균/중앙값 모델 선택, (4) 전체 달력과 공휴일 처리, (5) 95%·3일 회복 규칙입니다. 이번 진단은 어느 안을 최종 승인하지 않습니다. 고정 구성은 학습 기간만으로 선정 기준·최소 관측·제외 매출 비중·부분 모집단 명칭을 합의한 뒤 별도로 검증합니다.
회복 전달본의 recovery_uncertainty_note에 recovery_threshold·consecutive_days·holiday_policy를 기록했습니다. 기존 전달 형식을 유지하며 결합 뒤에도 note가 보존됩니다. 기준값 표시는 추적 정보이며 현재 join_metrics가 note를 자동 파싱해 다른 기준을 거부하는 기능은 없습니다. 사용할 실행 기록과 기준을 확인해야 합니다. 기존 #30 코드와 기본 회복 규칙은 변경하지 않았습니다.
prepare_sales_handoff.py의 세미콜론·한 줄 조건문을 줄바꿈해 정리했습니다. 실제 재실행에서 ALL 입력 4,420행 보존, 연령 회복 1,473행 유지, #31 ALL 판정 255행 일치, 전달본 1,728행 1:1 결합을 재확인했습니다. 연령 민감도 기본 경로도 현재 연령 결과 1,473행과 일치했습니다.
관련 테스트 30개가 일반 실행과 python -O에서 통과했습니다. 실제 결측이 있는 예상값의 비중 반영, 세 가지 결측 원인, 고정 제외·마지막 그룹 방지, 공휴일/비공휴일 범위 구분, 연령별 민감도와 전달 note 보존을 검사했습니다. 전체 main 테스트나 GitHub 자동 검사 통과를 주장하지 않습니다. Draft와 #12/#13 미완료를 유지하며 세은·조은의 최신 변경 검토 및 공동 기준 확인이 남아 있습니다.
