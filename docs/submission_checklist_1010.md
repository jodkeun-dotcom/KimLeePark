## 대회 요구와 내부 마감

2026-10-06 확인한 [공식 홈페이지](https://www.bigcontest.or.kr/)와 제공된 「2026 빅콘테스트 주제설명자료_260907.pdf」 4~5쪽을 기준으로, 제공 데이터 1종 이상 활용, 무료·공개 외부 데이터의 출처·수집방법·실제 사용 원본, 분석·모델링·성능·재현 코드, LLM 사용 시 구체적인 활용·분석 과정 설명을 준비한다. 공식 제출은 발표자료 형태이며 선택 보조 자료가 가능하다. 홈페이지에서 확인한 최종 제출일은 2026-10-26이며 팀 내부 10/11 완료 계획과 구분한다. 제출 직전 최신 양식·공지·제출 경로를 다시 확인한다.

외부 공공데이터의 원본 제출 요건과 SKT·신한카드 제공 원본 전체의 재제출 여부는 같은 조건이 아니다. 제공기관 자료의 공개 허용 범위를 넓혀 해석하지 않는다. 개인별 9일 초안 전체를 그대로 최종 제출한 것으로 처리하지 않는다.

## LLM 활용 설명 초안

조은은 Codex를 코드 작성·리뷰, 데이터 결합과 재실행 검증, 모델·상태 비교표 점검, 보고서·발표자료 초안과 문구 검토에 활용했다. 실제 값은 제공 데이터·공공데이터에서 계산하며, 테스트용 가상 자료를 실제 관측 자료와 섞지 않았다. HGB 예측 모델과 작업을 보조한 LLM은 구분한다. 재실행 비교·테스트 기록은 남겼지만 팀원이 직접 결과·해석을 설명할 수 있는지 최종 확인해야 한다.

세은의 Claude Code 활용 언급은 확인했지만 정확한 모델·기간·작업별 범위는 본인 기록으로 보완한다. 선하도 실제 사용 도구와 범위 및 독립 검증 내용을 확인해 적는다. 사용하지 않은 도구·실행하지 않은 검증은 추가하지 않는다.

## 파일 배치 제안

최종 제출본에는 발표자료, 보조 보고서, 재현 코드·환경, 데이터 출처·변수 설명·사용 외부 원본, LLM 활용 설명을 구분해 둔다. 제공 원본·정제값의 포함 범위는 대회 안내와 팀의 비공개 관리 기준에 맞춰 정한다. 현재 TEAM_INTERNAL ZIP은 팀 검토용이며 최종 제출 ZIP이 아니다.
