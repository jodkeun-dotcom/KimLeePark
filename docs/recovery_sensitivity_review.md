## 해석과 남은 결정

완전 연령 기준에서 자료 부족은 197/255(77.3%)이며, 그중 사건기간 그룹 불완전이 196건, 사건기간은 완전하지만 관찰기간 판정 자료가 부족한 경우가 1건입니다. 부분 합계 기준의 자료 부족 51건보다 146건 많습니다. 세은이 우려한 판정 가능 범위 축소가 실제로 확인됐습니다. 이는 지원 필요성이 낮다는 뜻이 아닙니다.
부분 합계와 완전 기준 사이 상태가 달라진 건수는 147건입니다. 부분 합계는 날짜마다 포함 연령이 달라질 수 있으므로 자료 부족이 적다는 이유만으로 최종 기준으로 채택할 수 없습니다. #30과 부분 합계의 차이는 집계·기준선 학습 방식까지 달라 완전성 조건 하나의 영향으로 해석하지 않습니다.
드문 연령만이 원인이라고 단정하지 않습니다. 현재 예측값 부재는 학습 관측 부족·공휴일 등의 영향을 함께 받습니다. 세은의 고정 구성 제안은 후속 후보로 기록합니다. 채택 전에 학습 기간만으로 연령 그룹을 선정할 기준, 최소 관측·요일 지원, 제외 매출 비중의 분모·결측 처리, 고정 그룹 감소 시 명칭을 공동 합의해야 합니다. 평가 결과를 보고 그룹을 골라 최종 ALL로 부르는 방식은 피하며, 부분 모집단 결과는 별도 명칭을 사용합니다. 이번 수정은 그룹을 자동 제외하거나 기본 회복 규칙을 변경하지 않습니다.

## 8/15 민감도

실제 입력에서 HEAT03 85건에만 관찰기간 공휴일 1일(8/15)이 있습니다. 두 건너뜀 비교 모두 총 85개 그룹-날짜를 제외했습니다. 완전 기준과 부분 기준 각각에서 회복 상태·회복 시작일 변화는 0건입니다. HEAT04·05에는 건너뛸 관찰기간 공휴일이 없습니다.
공휴일 건너뜀은 사건기간 판정을 바꾸지 않고 관찰기간 공휴일만 제거합니다. 일반 결측일은 여전히 연속을 끊습니다. 회복일수는 사건 종료 이후 달력일 간격을 유지하며, 3일은 공휴일을 제외한 연속 평가일이라는 다른 의미입니다. skipped_holiday_days는 별도 열과 note에 남깁니다.
가상자료에서는 8/14·16·17이 기준 이상이고 8/15만 예측 불가일 때, 기존 방식은 censored이고 건너뜀은 recovered로 바뀝니다. 실제 자료의 변화 0건은 두 규칙이 항상 같다는 뜻이 아닙니다. 전체 공휴일 달력 #27 연결 후 민감도를 다시 확인해야 합니다. 건너뜀은 탐색 비교용이며 기본 전달본에 적용하지 않았습니다.

## 전달 경로와 검증

공통 기준선 연결 검토의 회복 전달 파일은 recovery_handoff_common_baseline.csv 하나로 지정합니다. 기존 #30 recovery_handoff.csv는 비교·회귀 확인용입니다. 민감도 결과 ALL_recovery_sensitivity_REVIEW_ONLY.csv는 결합 입력이 아닙니다. 최종 우선순위로 채택하는 결정은 공동 검토 후입니다.
새 민감도 결과의 기본 완전 기준은 실제 #32 회복 상태·일수 255행과 일치합니다. #31과의 255행 일치, ALL 원래 입력값 4,420행 보존, 연령별 회복 1,473행 유지, 전달표 1,728행 결합도 재확인했습니다.
관련 테스트 24개가 일반 실행과 python -O에서 통과했습니다. 가상 공휴일 영향, 일반 결측일 처리, 부분/완전 그룹 분리, 잘못된 창·달력·규칙 거부를 포함합니다. 전체 main 테스트와 GitHub 자동 검사는 이번 실행 범위에 포함하지 않습니다. Draft와 #12/#13 미완료를 유지하며 세은의 추가 검토를 기다립니다.
