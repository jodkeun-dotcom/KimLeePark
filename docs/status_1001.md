## 로컬에서 완료한 내용

- [x] SKT 18개 파일 점검 및 지정된 12월 파일의 완전 중복 제거

원본·레이아웃·정제 및 요약 CSV는 공개 저장소에 포함하지 않는다. 결과는 로컬에서 재생성하며, 팀 공유는 제공 조건에 맞는 경로를 이용한다. 입력 및 출력 경로는 데이터 준비 안내에 설명했다.

## 검증 기록

- 최초 SKT 중복 제거: 12월 시간대 92,545행, 요일별 121,267행, 합계 213,812행.
- 최초 전처리에서 결측값·음수·상충하는 키 없음 확인.
- 이미 중복 제거한 압축 SKT 18개로 재실행했을 때 추가 제거 0행 및 기존 요약·격자 결과 일치 확인.
- 신한카드 데이터1 재실행: 60대 이상 통합 후 일별 68,455행, 월별 36행. 집계 전후 금액·건수 합계 보존.
- 결합 검사 5개: 행수·금액 보존 및 측정값 결측 유지, 중복 기상행 차단, 달력/기상 날짜 누락 차단, 미확정 지역표 차단 및 확정표 결합.

## 10월 2일 PR #25 리뷰 반영

공개 저장소에는 코드·문서·메타정보를 남기도록 제공 원본·레이아웃과 정제·요약 CSV를 최신 파일 상태에서 제외했다. `.gitignore`는 `data/README.md`, `data/manifest.json` 외의 데이터 및 로컬 분석 출력 경로를 제외한다. 실행 방법도 로컬 입력 준비 방식으로 바꿨다. 로컬 원본은 보존하며 과거 Git 기록을 삭제한 것은 아니다.
