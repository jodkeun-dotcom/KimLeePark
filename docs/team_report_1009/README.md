- 세 사람의 개인 최종 첨부 8개를 기준으로 보고서 내용을 통합했다.
- 사건×업종 54행, 전체 ALL 255행, 업종×연령×사건 1,473행을 구분했다.
- 사건 직전 사전 검증과 이후 기간 모델 비교의 WAPE를 구분했다.
- 회복 첫날·확인 완료일, 순누적 부족·양의 일별 부족분 합계, full/eligible/paired 창을 구분했다.
- 감소율 순위와 상태별 검토표의 차이를 설명하고 방법의 우수성은 주장하지 않았다.
- 사건 종료일 E, 개별 검토 착수일 D, 실제 지원 시작일 S를 구분했다.
- v1 대비 표의 수치를 유지하면서 결론·미확인 해석·중앙값 표본·평가 단위·용어를 보완했다.
- 원본 개인 자료와 통합 표를 대조하고 주요 분모 합계 및 8쪽 전체 배치를 확인했다. 새 모델 학습이나 결과 재계산은 하지 않았다.
