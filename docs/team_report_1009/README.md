## 근거와 검증 범위

세 사람 개인 최종 첨부 8개의 기준 버전·해시는 유지했다. 보고서 표의 수치는 이전 통합본과 모두 동일하다. 회복 첫날·확인 완료일, 순누적 부족·양의 일별 부족분 합계, full/eligible/paired, 사전 검증·이후 기간 모델 비교, E/D/S 날짜 구분도 유지한다.

예상값 비중은 회복 상태가 insufficient_data가 아닌 **58/255개 조합**을 대상으로 한다. 분자는 그 58개 조합의 알려진 연령별 예상값 합, 분모는 전체 255개 조합의 알려진 연령별 예상값 합이다. 실제 관측 유무와 무관하게 존재하는 예상값을 포함하고 예상 부재 셀은 보충하지 않는다. 상세 진단표를 합산한 값은 사건기간 63.1526509628%, 사건~유효 관찰 종료 68.5193703011%로, 소수 한 자리 표시가 63.2%·68.5%다. 이는 사건 창 평가 단위를 합친 비중이며 춘천 전체 매출 커버리지가 아니다.
