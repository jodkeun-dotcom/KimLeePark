# AI·공통 기준모델 비교 계획 — 2026-10-04

관련 업무: #10 → #13. **실험 준비 단계이며 실자료 모델 학습·성능 비교 완료가 아니다.**

## 목적과 담당

- 선하(#9): 공통 기준모델 코드·산식·예상 매출 및 학습 범위를 공유한다.
- 조은: 같은 조건에서 AI 모델 1종과 비교하고 이후 기간의 성능을 확인한다. 다른 기준모델을 임의로 만들어 선하의 결과로 대체하지 않는다.
- 세은(#8): 사건·회복 결과를 제공한다. 예측모델 성능 평가와 폭염 이후 회복·지원 우선순위 해석은 별도로 검토한다.

예측 대상은 `date × region × industry × age`별 개인카드 `amount`다. 제공 단위를 그대로 사용한다. 카드 데이터2와 합산하지 않는다. 해당 조합의 행이 없는 날짜는 매출 0으로 채우지 않는다.

## AI 1종과 입력

**HistGradientBoostingRegressor**를 비교 후보로 준비했다. 초기 설정은 squared_error, learning_rate=0.05, max_iter=100, max_leaf_nodes=15, l2_regularization=1, random_state=42다. 임의 날짜가 섞이는 내부 조기종료 분할을 사용하지 않도록 `early_stopping=False`로 둔다.

| 구분 | 초기 입력안 | 원칙 |
|---|---|---|
| 업종·연령 | industry, age | 학습 구간에서만 범주 인코더 적합, 새 범주 별도 보고 |
| 달력 | 요일, 주말 여부, 월, 7/1부터 경과일 | 예측 시점에 알 수 있는 값만 사용 |
| 공휴일 | 전체 달력 수신 후 추가 검토(#27) | 현재 빈 날짜를 비공휴일로 채우지 않음 |
| 기상 | 초기 버전에서 제외 | 이후 추가 시 관측 날씨를 사용한 사후 추정과 사전 예측을 구분 |
| SKT | 모델 입력에서 제외 | 해당 월 전체 통계·6개월 공통 격자는 과거 설명용 |
| 결제건수·당일 실제 매출 | 입력에서 제외 | 예측할 당일 결과가 입력에 섞이지 않도록 함 |

월과 경과일의 미래 값에 대해 나무 모형의 추세 외삽이 제한될 수 있다. 이후 계절에서 성능이 낮아지면 그 결과를 그대로 보고한다. 학습 목표는 원 단위 매출이며, 최종 예측이 음수인 모형은 두 모형에 동일한 사전 결정 처리 규칙을 적용한다.

## 날짜 분할 초안

| 용도 | 학습 | 평가 | 사용 목적 |
|---|---|---|---|
| 검증 | 2025-07-01~08-31 | 2025-09-01~09-30 | 초기 설정·입력 결정 |
| 최종 보류 평가 | 2025-07-01~09-30 | 2025-10-01~12-31 | 설정 확정 후 한 번 평가 |

같은 날짜가 학습·평가에 동시에 들어가지 않는다. 전처리도 학습 구간에서만 적합한다. 테스트 매출을 확인해 업종·연령 집단을 선택하지 않는다. 학습에 없던 집단의 관측 수와 성능은 따로 표시한다. 현재 분할 CSV는 준비만 했으며 실자료 모델 적합과 시험 성능은 아직 산출하지 않았다.

선하의 공통 기준모델이 사용하는 학습 범위·재학습 방식과 이 분할을 먼저 맞춰야 한다. 서로 다른 학습 정보로 만든 기존 예상 매출을 바로 성능 비교에 넣지 않는다. 일정 변경 시 두 모형을 같은 분할로 다시 실행한다.

이 가을·겨울 평가는 **이후 기간의 매출 예측 성능**을 확인한다. 여름 폭염이 없었을 때의 매출을 관측한 것은 아니다. 회복 분석용 예상 매출은 사건 전 정보와 비사건일 선정 등 별도 설계가 필요하며, 10~12월 정보로 여름 사건을 설명한 값을 사전 예측이라고 부르지 않는다.

## 공통 성능지표

- MAE: 평균 절대 오차. 원 자료 금액 단위.
- RMSE: 큰 오차에 민감한 보조 지표. 원 자료 금액 단위.
- WAPE: 절대 오차 합 / 실제 금액 합. 실제 합이 0이면 산출 불가로 표시한다.
- 업종별·연령별 MAE/WAPE 및 그룹별 결과 분포, 평가 가능 행 수·결측 예측 수·학습에 없던 집단 수를 함께 보고한다. 큰 업종에 전체 점수가 좌우되는지 확인한다.

`paired_metrics`는 평가 키가 하나라도 다르거나 예측이 누락되면 중단한다. 두 모형이 같은 실제 매출 행을 예측했는지 먼저 확인한다. 임의로 교집합만 남겨 성능을 높이지 않는다. MAPE는 실제 매출 0에서 정의되지 않아 초기 공통 지표에서 제외했다.
