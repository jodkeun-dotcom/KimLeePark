# 회귀모형 로컬 검증 기록

검증일: 2026-10-26. 기준 코드: main `6883a47c340a49541f1dc83f16962e7c59b4511b`.

## 확인한 사항

- 기존 공통 분석 입력 카드·사건·관찰창·전체 공휴일 파일의 SHA-256이 과거 모형 비교 실행과 동일함을 확인했다.
- 기존 요일 평균·HistGradientBoosting을 재학습하여 과거 관측 키, 실제값, 예측값, 평가 자격과 대조했다. 허용오차 rtol=1e-9, atol=1e-6에서 일치했다.
- 기본 Ridge를 같은 학습자료로 재학습하여 예측값의 반복 일치를 확인했다.
- 전체 suite를 독립 프로세스에서 재실행했다. 성능표·검증 후보·음수 예측 감사표·검증/평가 예측표와 선택 설정이 일치했다. 수치 대조 허용오차 rtol=1e-12, atol=1e-6.
- 저장된 실제값·예측값에서 WAPE·MAE·RMSE를 별도로 다시 계산하여 전체 성능표와 대조했다.
- 가상자료 테스트 10개를 로컬에서 통과했다. 지표 산식, 학습 전용 표준화, 미관측 범주, 조합 키 충돌, 평가 제외 행의 선택 영향, 기준 결과 불일치 거부, 예측 시 타깃 미사용, 세 모형 진입점의 단일 모형 선택을 확인한다.
- 결과 그래프를 렌더링하여 수치·레이블·잘림을 확인했다.

## 결과 해석

기본 Ridge의 조합항 보완은 이번 표본의 WAPE를 개선했으나 요일 평균을 대체할 근거로 충분하지 않았다. 요일 중앙값은 WAPE·MAE, 요일 평균은 중앙값 대비 RMSE에서 유리하여 지표별 선택이 다르다. 새로운 회귀모형의 후보 범위가 제한되어 있어 알고리즘 일반의 우열로 단정하지 않는다.

실제 성능 수치·선택 설정·집단별 오차와 예측값은 팀 내부 결과 묶음에서 확인한다. 이 문서는 공개 가능한 검증 방법과 상태만 기록한다.

## 검증 범위의 한계

팀원 독립 실행이나 GitHub CI를 통과했다는 뜻은 아니다. 10~12월은 이미 관찰된 벤치마크이며 이번 결과는 사후 비교다. 예측 실험을 수행했지만 사건별 회복·순누적 부족·지원 분류를 신규 모델로 교체하지 않았다. 별도 리뷰와 재계산 없이 주 분석 기준선 또는 정책 결론을 변경하지 않는다.
